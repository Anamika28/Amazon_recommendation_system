# Amazon Product Recommendation System

This project implements a recommendation engine for Amazon products using collaborative filtering techniques. It leverages user-product rating data to predict user preferences and suggest relevant items. The system explores both user-user and item-item K-Nearest Neighbors (KNN) methods, as well as matrix factorization using SVD.

### Features:
- Data preprocessing and exploratory analysis
- User-user and item-item collaborative filtering
- Matrix factorization using SVD
- Evaluation using RMSE and precision-recall
- Comparison of model performance

### Tech Stack:
- Python, Pandas, Scikit-learn, Surprise
- Google Colab environment
